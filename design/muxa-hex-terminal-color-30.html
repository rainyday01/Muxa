比例 为什么 HTML 里的六边形比手机上的小

原因不是「两套画法」，而是三层缩放叠在一起：
  • HTML 原图 SVG（design 文件）：六边形几乎铺满 108 画布（无额外缩小）→ 看起来最大。
  • APK 矢量：整组 scale(0.72) 居中，给自适应图标留安全边 → 比原图小。
  • 桌面启动器：多数机型会对 Adaptive Icon 再放大并圆形/圆角裁剪（约 10%–25%），安全边被吃掉 → 肉眼上六边形又变「大」、贴边。
上一份 HTML 的 A 组 = APK 矢量比例（0.72），所以比你手机桌面上的观感更「收」。 本页目标比例：以 A 组 / HTML 展示为准的呼吸感；APK 将改为 scale(0.62)，抵消桌面二次放大后，接近本页「目标」预览。
