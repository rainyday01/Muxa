m-tmux · 10 套差异化 UI 设计方案

面向远程 tmux / Claude·Grok TUI 的移动客户端。每套方案在导航、密度、色彩、信息架构上刻意拉开差异；每套含 5 个核心界面高保真线框（Claude TUI 会话、窗口列表、主机列表、设置、字体/主题预览）。

产品 m-tmux 日期 2026-07-24 交付 交互 HTML · 点方案切换 研究 Termius / Blink / Prompt 3 / Material 3 / Fluent / Warp·Moshi 范式

调研摘要 · 可参考产品

Termius

跨平台 SSH 标杆：卡片主机、底栏三 tab、主题/字号 per-host、手势特殊键。信息架构清晰，订阅驱动 polish。

Blink Shell

键盘优先、几乎无 chrome 的「手机上的 shell」。极简列表、Mosh 一等公民、字体/主题深度定制。

Prompt 3 (Panic)

设计驱动的 iOS SSH：暖色暗调、精致圆角与排版、细节打磨高于功能密度。

Moshi / Warp 类 Agent

为 Claude Code 等 agent 优化：状态条、审批、分屏预览。会话=工作流，不是纯 PTY。

Material 3 / Now in Android

大标题、色块 surface、FAB、圆角列表。Android 原生可识别度最高。

Apple HIG · Glass

毛玻璃、浮动底栏、深度与留白。适合「高级感」路线。

Raycast / Linear

命令面板 + 极简行列表；或浅色生产力。密度与键盘文化。

Fluent / Termux 美学

左侧导航（桌面感）或 CRT 绿字极客美学——两端分化的可识别身份。

说明：界面为设计探索 mock，非最终实现。选型建议：默认推荐 方案 1（Termius 系） 作为增量改版成本最低路径；若强调 AI Coding 会话，优先评估 方案 6；若要强品牌差异，评估 5 Glass 或 8 CRT。
