# m-tmux 全功能端到端测试用例

> **版本范围：** 基于 v0.3.1 已实现能力（APK 线约 `0.1.7-truecolor` 及同功能树）  
> **类型：** 手工真机 / 半自动（可配合桌面 `tmux` / `ssh` / `mosh` 对照）  
> **排除：** Backlog（一键代装、命令面板 UI、推送到电脑 UI、Companion、iOS）  
> **记录：** 每条用例结果填 `Pass / Fail / Blocked / N/A`，备注栏写设备与构建号  

---

## 0. 测试准备

### 0.1 构建与安装

| 项 | 要求 |
|----|------|
| 被测包 | `app.mtmux.android` debug/release，记录 `versionName` / `versionCode` |
| 安装 | 卸载旧包 → 安装 → 冷启动 |
| 权限 | 网络；应用锁用到生物识别/设备凭证时按系统引导 |

### 0.2 环境矩阵（建议至少 2 类主机）

| 代号 | 主机类型 | 必备软件 | 用途 |
|------|----------|----------|------|
| **H-SSH** | 公网或 Tailscale Linux VPS | `sshd` + `tmux` | 主路径 SSH |
| **H-MOSH** | 同或另一台 | + `mosh-server`，**UDP 60000–61000 放行** | Mosh / AUTO |
| **H-BARE** | 干净机或容器 | 仅 `sshd`，**无** tmux/mosh | 安装向导 |
| **H-KEY** | 任意 | 仅公钥登录 / 仅密码 / 带口令私钥 | 认证矩阵 |
| **H-DUAL** | 与桌面共用 | 桌面 Termius/SSH 已建会话 | 双 socket 互通 |

**桌面对照工具：** `ssh`、`tmux ls`、`tmux attach`、可选 `mosh`。

### 0.3 账号与材料

- [ ] 密码主机一组  
- [ ] Ed25519 / RSA 私钥 PEM（含可选 passphrase）  
- [ ] 错误密码 / 错误密钥各一组  
- [ ] 片段测试文案、键盘 JSON 样例（见 `protocols/keyboards/`）  
- [ ] 加密导出用密码（≥8 字符建议）
