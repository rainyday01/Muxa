# 应用命名：m-tmux 与备选

> 非法律意见；上架前如有商业化计划，建议再做商标检索或咨询律师。

---

## 1. m-tmux 是否「侵权」？

### 1.1 开源许可证（版权）

- **tmux** 本身以 **ISC** 等宽松许可分发，允许商业使用、修改、再分发。  
- 许可常见约束是：**不能暗示得到原作者/项目背书**（non-endorsement），以及保留版权声明（若你 redistribute 其代码）。  
- **仅做一个「连接远程 tmux」的客户端、不 fork 其代码**，一般不触发「衍生作品必须如何命名」的版权问题。  
- **版权 ≠ 商标**：许可证宽松 **不等于** 品牌名可以随便当自己的主商标用。

### 1.2 商标与混淆风险（真正要注意的）

| 风险点 | 说明 |
|--------|------|
| **来源混淆** | 用户可能以为 `m-tmux` 是 **官方 tmux 移动版**（类似「官方 Android 客户端」） |
| **应用商店审核** | 名称/截图若过度使用 tmux 标识，可能被要求改名或补充免责 |
| **正式商标** | 公开资料里 tmux 更以开源项目名存在；**是否在各国注册商标需专项检索**，不能默认「没注册就绝对安全」 |
| **域名/商店冲突** | `m-tmux`、`mtmux` 等包名、商店 id 仍可能被抢注或冲突 |

### 1.3 结论（产品建议）

| 用法 | 建议 |
|------|------|
| 副标题 / 功能描述：「Mobile tmux client」「连接远程 tmux 会话」 | ✅ 清晰、风险低 |
| 主品牌整词 **m-tmux / MTmux / tmux Mobile** | ⚠️ **可用作工作名**，有 **官方感/混淆** 风险；上架与商业化前建议检索 + 文案免责 |
| Logo 照搬 tmux 官方视觉 | ❌ 不建议 |
| 宣传「Official tmux」 | ❌ 禁止 |

**务实策略：**

1. **技术包名**可用中性 id（如 `app.mtmux` / `life.eds.mtmux`），与展示名解耦。  
2. **商店展示名**优先「自有品牌 + 副标题含 tmux」。  
3. 关于页写明：**Not affiliated with the tmux project.**  
4. 若坚持主名含 tmux：用 **m-tmux** 比直接叫 **tmux** 略好（有「第三方/移动端」修饰），仍建议加免责声明。

## 2. 命名方向评估

### 2.1 m-tmux（你的提案）

| 优点 | 缺点 |
|------|------|
| 语义直达：移动端 tmux | 依赖 tmux 品牌认知，有混淆风险 |
| 极客受众秒懂 | 非开发者看不懂；商店搜索可能被「tmux 教程」类内容淹没 |
| 短、好念 | 国际化写 `m-tmux` 连字符在口语/图标上略别扭 |

** entence：** 可作 **内部/技术向工作名**；若作最终商店名，配套免责 + 副标题。

### 2.2 推荐备选（代表「移动端 × 会话/窗格/附着」）

| 名称 | 语感 | 说明 |
|------|------|------|
| **Attach** | 动词，直指 `tmux attach` | 短、动作清晰；通用词需查重 |
| **Mux** | 极客缩写 | 短；可能与其它 mux 产品撞车 |
| **Pane** | tmux 窗格 | 优雅；需查重 |
| **Session** / **Sessions** | 会话一等公民 | 直白；略泛 |
| **MoshMux** | SSH+Mosh+mux | 偏长、偏技术 |
| **Clip** / **Latch** | 夹住/闩上远程会话 | 品牌感强，需解释 |
| **Remux** | re-attach + mux | 好听；查重 |
| **mtmux**（无连字符） | 同 m-tmux | 包名友好 |
| **Tabmux** / **Phonemux** | 手机 mux | 略土 |
| **前台** 中文市场 | 「窗格」「附着」 | 国内另议英文主名 |

### 2.3 综合推荐（产品视角）

| 优先级 | 名称 | 理由 |
|--------|------|------|
| **首选品牌** | **Attach** 或 **Remux** | 不直接占用 tmux 主商标位，副标题写 *Mobile tmux client* |
| **可接受工作名** | **m-tmux** / **mtmux** | 你偏好、语义准；上架时加强免责与副标题 |
| **原 Pane** | 可作模块/项目目录名保留 | 已在仓库使用，可与商店名分离 |

**副标题统一建议：**

> m-tmux — Mobile client for remote tmux sessions  
> 或：Attach — Jump into remote tmux from your phone
