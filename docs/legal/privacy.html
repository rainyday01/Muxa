Muxa Privacy Policy

Effective 14 September 2026 · Product: Muxa (iOS) · Bundle ID: app.mtmux.ios

Muxa is a native SSH and tmux terminal. It does not require a Muxa account, does not include ads or analytics SDKs, and does not operate a central server for your sessions.

Data stored on your device

Host names, usernames, session lists, snippets, keyboard layouts, and preferences are stored locally. Passwords, private keys, and related secrets are stored in the iOS Keychain using This Device Only accessibility and without a shared Keychain access group.

Network traffic

When you connect, traffic goes only between your device and the SSH hosts you configure. Session content is not routed through Muxa-operated servers.

Diagnostics

Muxa does not upload logs to a Muxa server. You may export or share a locally redacted log using the system share sheet. Muxa receives that file only if you send it yourself.

Device identifiers

Muxa does not send Identifier for Vendor or other device identifiers to Muxa-operated servers.

Deletion

  • Deleting a host removes that host’s Keychain secrets immediately.
  • Settings → Privacy → Delete all data on this device removes every Muxa Keychain item and saved host on the device.
  • Uninstalling Muxa removes those This-Device-Only Keychain items because they are not in a shared access group.

Children

Muxa is a developer tool and is not directed at children.

Muxa 隐私政策

Muxa 是原生 SSH / tmux 终端。无需 Muxa 账号，不含广告或分析 SDK，也不会把你的会话经过 Muxa 运营的中央服务器。

主机、会话、片段和偏好保存在本机；密码与私钥保存在 iOS Keychain（仅本机、无 iCloud 共享组）。网络只到达你配置的 SSH 主机。诊断日志不会自动上传，仅在你导出或系统分享时离开本机。删除主机或使用「删除本机全部数据」会清除对应 Keychain 项；卸载应用也会清除这些仅本机 Keychain 项。
