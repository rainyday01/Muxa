Muxa Privacy Policy

Effective 30 October 2026 · Muxa for Android (app.mtmux.android) and iOS (app.mtmux.ios)

Muxa is an SSH and tmux client. It has no accounts, no ads and no analytics or crash-reporting SDKs. Your terminal sessions go directly between your device and the servers you configure; they never pass through a Muxa server.

Data stored on your device

Host names, ports, usernames, session lists and screen snapshots, snippets, command history used for completion, keyboard layouts and settings are stored only on your device. Passwords, private keys and key passphrases are encrypted with a key held in the Android Keystore (Android) or stored in the Keychain with This Device Only access (iOS). Android system backup is turned off for Muxa.

Network connections

Muxa connects only to the SSH hosts you add. When completion is on, Muxa runs small commands on that host (for example to list file names) over the same SSH connection.

Feedback you choose to send

Nothing is uploaded automatically. If you tap Send to developer under Settings → Diagnostics, Muxa uploads to the developer's log server (loginfo.xcodeuk.com):

  • the app's diagnostic log, which can contain host names or IP addresses, usernames, tmux session names and short excerpts of terminal output;
  • your note, the app version, the device manufacturer and model, the OS version, and a random ID created when the app is installed (not a hardware or advertising ID).

Passwords, private keys and passphrases are never written to the log. Uploads are used only to diagnose the problem you report and are deleted once they are no longer needed for that.

If you choose GitHub issue instead, Muxa first removes IP addresses, host names, usernames, session names and screen text from the log, saves it as a file you control, and opens a GitHub issue form. Anything you post on GitHub is public and governed by GitHub's terms.

Exports

An encrypted config export (and, if you opt in, the passwords and keys inside it) leaves your device only where you save or paste it. It is encrypted with the password you choose; Muxa cannot recover it.

Sharing

We do not sell personal data or share it with third parties for advertising or any other purpose.

Deletion

  • Deleting a host removes its saved secrets immediately.
  • Settings → Privacy → Delete all data on this device erases everything Muxa stores on the device.
  • Uninstalling Muxa removes its local data. To have a feedback upload deleted sooner, email us with the reference shown after sending.

Children

Muxa is a developer tool and is not directed at children.

Changes and contact

Muxa 隐私政策

生效日期 2026 年 10 月 30 日 · 适用于 Muxa Android 版（app.mtmux.android）与 iOS 版（app.mtmux.ios）

Muxa 是 SSH / tmux 客户端，无需账号，不含广告、统计或崩溃上报 SDK。终端会话只在你的设备和你配置的服务器之间传输，不经过 Muxa 的服务器。

保存在本机的数据

主机名、端口、用户名、会话列表与快照、命令片段、用于补全的命令历史、键盘布局和设置只保存在本机。密码、私钥和私钥口令在 Android 上用 Android Keystore 中的密钥加密保存，在 iOS 上保存在仅本机可用的钥匙串中。Android 版关闭了系统备份。

网络连接

Muxa 只连接你添加的 SSH 主机。开启补全时，Muxa 会通过同一条 SSH 连接在该主机上执行少量命令（例如列出文件名）。

你主动发送的反馈

Muxa 不会自动上传任何内容。只有在「设置 → 诊断」里点击「发送给开发者」时，才会上传到开发者的日志服务器（loginfo.xcodeuk.com）：应用诊断日志（可能包含主机名或 IP、用户名、tmux 会话名和少量终端输出片段），以及你的备注、应用版本、设备厂商和型号、系统版本、安装时随机生成的 ID（不是硬件 ID 或广告 ID）。密码、私钥和口令从不写入日志。上传内容只用于排查你反馈的问题，不再需要时即删除。

如果选择「提 GitHub Issue」，Muxa 会先去掉日志中的 IP、主机名、用户名、会话名和屏幕文字，保存为你自己掌握的文件，再打开 GitHub 的 Issue 页面。发布在 GitHub 上的内容是公开的，受 GitHub 条款约束。

导出

加密配置导出（以及你选择包含的密码和私钥）只会去到你保存或粘贴的位置，并用你设定的密码加密，Muxa 无法找回。

共享

我们不出售个人数据，也不会出于广告或其他目的与第三方共享。

删除

删除主机会立即清除其保存的密钥；「设置 → 隐私 → 删除本机全部数据」会清除 Muxa 在本机保存的全部内容；卸载 Muxa 也会删除本地数据。如需尽快删除某次反馈上传，请发邮件并附上发送后显示的编号。

儿童

Muxa 是开发者工具，不面向儿童。
